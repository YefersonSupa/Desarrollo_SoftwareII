% --- 2. FUNDAMENTOS TEÓRICOS ---
\section{Fundamentos Teóricos}

\subsection{Evolución y Paradigmas de Desarrollo Móvil}
El ecosistema de desarrollo móvil clasifica sus soluciones según su estrategia de ejecución y renderizado:
\begin{itemize}[leftmargin=*]
    \item \textbf{Desarrollo Nativo Puro (Kotlin/Java en Android, Swift en iOS):} Proporciona acceso directo al hardware y a las últimas APIs de la plataforma, pero exige duplicar esfuerzos de codificación y mantenimiento.
    \item \textbf{Desarrollo Híbrido (Cordova, Capacitor):} Empaqueta aplicaciones web en un contenedor nativo (\textit{WebView}), lo cual simplifica la multiplataforma pero penaliza el rendimiento y la fluidez gráfica.
    \item \textbf{Compilación Multiplataforma Reactiva (Flutter):} Enfoque adoptado en este proyecto. Flutter evita los puentes de comunicación (\textit{bridges}) y el renderizado a través de widgets nativos del sistema operativo; en su lugar, utiliza su propio motor gráfico (Impeller / Skia) para dibujar cada píxel directamente en un lienzo (\textit{Canvas}) a 60 o 120 FPS.
\end{itemize}

\subsection{Arquitectura Reactiva y Widgets en Flutter}
En Flutter rige el principio de que \textbf{todo elemento en la interfaz es un widget}. La interfaz de usuario es el reflejo directo del estado interno:
\begin{equation}
    UI = f(state)
\end{equation}

\begin{itemize}[leftmargin=*]
    \item \textbf{\texttt{StatelessWidget}:} Representa componentes cuya configuración es estática e inmutable durante su ciclo de vida (por ejemplo, iconos, textos fijos, el andamiaje del tema).
    \item \textbf{\texttt{StatefulWidget}:} Componente compuesto por dos clases: la definición del widget inmutable y una clase \texttt{State} persistente. Cuando los datos subyacentes cambian, la llamada a \texttt{setState()} programa la reconstrucción del subárbol de widgets (\textit{re-render}), actualizando la vista de forma eficiente.
    \item \textbf{Hot Reload vs. Hot Restart:} El motor Dart en modo depuración (\textit{JIT - Just-In-Time}) inyecta el código fuente actualizado directamente en la máquina virtual Dart en menos de un segundo, conservando el estado de la aplicación sin reiniciar el proceso.
\end{itemize}

\section{Desarrollo e Implementación del Proyecto ``Hola Mundo''}

\subsection{Creación y Organización de la Estructura}
El proyecto fue inicializado con la convención de dominio invertido institucional:
\begin{lstlisting}[language=bash, numbers=none]
$ flutter create --org pe.edu.unsaac hola_mundo
\end{lstlisting}

La arquitectura resultante se organiza según los estándares modernos:
\begin{itemize}[leftmargin=*]
    \item \texttt{android/}: Contiene el proyecto Gradle para Android, el paquete nativo \texttt{pe.edu.unsaac.hola\_mundo} y el manifiesto \texttt{AndroidManifest.xml}.
    \item \texttt{lib/}: Directorio donde reside la lógica Dart de la aplicación.
    \item \texttt{lib/main.dart}: Punto de entrada principal con los widgets \texttt{UnsaacMobileApp} y \texttt{HolaMundoScreen}.
    \item \texttt{pubspec.yaml}: Manifiesto del proyecto que declara la versión 1.0.0+1, SDKs compatibles y dependencias como \texttt{cupertino\_icons} y \texttt{flutter\_lints}.
    \item \texttt{test/widget\_test.dart}: Suite de pruebas de humo y validación de interfaz.
\end{itemize}

\subsection{Código Fuente Implementado (\texttt{lib/main.dart})}
Se diseñó una interfaz enriquecida con \textbf{Material Design 3}, integrando los colores institucionales de la UNSAAC, tarjetas de presentación estructuradas, un carrusel dinámico de mensajes reactivos y un contador de interacciones:

import 'package:flutter/material.dart';

void main() {
  // Punto de entrada de la aplicacion movil

class UnsaacMobileApp extends StatelessWidget {
  const UnsaacMobileApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'UNSAAC - Desarrollo Movil',
      debugShowCheckedModeBanner: false,
      theme: ThemeData(
        useMaterial3: true,
        colorScheme: ColorScheme.fromSeed(

/// Pantalla principal interactiva (Stateful: su interfaz cambia reactivamente)
class HolaMundoScreen extends StatefulWidget {
  const HolaMundoScreen({super.key});

  @override
  State<HolaMundoScreen> createState() => _HolaMundoScreenState();
}

class _HolaMundoScreenState extends State<HolaMundoScreen> {
  int _contadorSaludos = 0;
  int _indiceMensaje = 0;

  // Lista dinamica evaluada por getter (optimiza el Hot Reload con Ctrl+S)
  List<String> get _mensajes => [
    '¡Hola mundo!📱',
    'Bienvenido a Desarrollo de Aplicaciones Moviles',
    'UNSAAC - Ingenieria Informatica y de Sistemas',
    'Construido con Flutter y Dart en tiempo record 🚀',
  ];

  void _cambiarMensaje() {
    // setState notifica a Flutter que el estado cambio y redibuja la UI
    setState(() {
      _contadorSaludos++;
      _indiceMensaje = (_indiceMensaje + 1) % _mensajes.length;
    });
  }

  @override
  Widget build(BuildContext context) {
    final theme = Theme.of(context);

    return Scaffold(
      appBar: AppBar(
        title: const Text(
          'IF616AIN - UNSAAC',
          style: TextStyle(fontWeight: FontWeight.bold),
        ),
        centerTitle: true,
        backgroundColor: theme.colorScheme.primaryContainer,
        foregroundColor: theme.colorScheme.onPrimaryContainer,
      ),
      body: SafeArea(
        child: SingleChildScrollView(
          padding: const EdgeInsets.all(20.0),
          child: Column(
            crossAxisAlignment: CrossAxisAlignment.stretch,
            children: [
              // Tarjeta principal de presentacion
              Card(
                elevation: 4,
                shape: RoundedRectangleBorder(
                  borderRadius: BorderRadius.circular(16),
                ),
                child: Padding(
                  padding: const EdgeInsets.all(24.0),
                  child: Column(
                    children: [
                      Icon(
                        Icons.smartphone_rounded,
                        size: 72,
                        color: theme.colorScheme.primary,
                      ),
                      const SizedBox(height: 16),
                      Text(
                        _mensajes[_indiceMensaje],
                        textAlign: TextAlign.center,
                        style: theme.textTheme.headlineSmall?.copyWith(
                          fontWeight: FontWeight.bold,
                          color: theme.colorScheme.primary,
                        ),
                      ),
                      const SizedBox(height: 12),
                      Text(
                        'Producto 1: Aplicacion basica "Hola Mundo movil"',
                        textAlign: TextAlign.center,
                        style: theme.textTheme.bodyMedium?.copyWith(
                          color: theme.colorScheme.onSurfaceVariant,
                        ),
                      ),
                    ],
                  ),
                ),
              ),
              const SizedBox(height: 24),

              // Tarjeta informativa con los datos del curso
              Card(
                elevation: 1,
                color: theme.colorScheme.surfaceContainerHighest,
                shape: RoundedRectangleBorder(
                  borderRadius: BorderRadius.circular(12),
                ),
                child: Padding(
                  padding: const EdgeInsets.all(16.0),

                          fontWeight: FontWeight.bold,
                        ),
                      ),
                      const Divider(),
                      _buildInfoRow('Curso:', 'Desarrollo de Aplicaciones Moviles'),
                      _buildInfoRow('Codigo:', 'IF616AIN (2 Creditos)'),
                      _buildInfoRow('Docente:', 'CCACYAHUILLCA-BEJAR-HANS HARLEY'),
                      _buildInfoRow('Eje actual:', 'Fundamentos del desarrollo movil'),
                    ],

              const SizedBox(height: 24),

              // Badge indicador de interacciones
              Center(
                child: Container(
                  padding: const EdgeInsets.symmetric(horizontal: 20, vertical: 12),
                  decoration: BoxDecoration(
                    color: theme.colorScheme.primary.withValues(alpha: 0.1),

import 'package:flutter_test/flutter_test.dart';
import 'package:hola_mundo/main.dart';

void main() {
  testWidgets('Prueba de humo para UnsaacMobileApp', (WidgetTester tester) async {
    // Construir la app y renderizar el primer frame
    await tester.pumpWidget(const UnsaacMobileApp());

    // Verificar que el saludo inicial esta presente

}
